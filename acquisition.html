Repository Acquisition Panel

Whole-repository acquisition, day by day. Outside systems that pull an entire repository register as clones. This panel separates those pulls from the repository's own CI, lines them up against each deposit, and places each day against the Torsion Limit TL = 0.136899099984016. The site section does the same for uuia.app and proofpress.org: every AI and search crawler by name and operator, the live assistant fetches made for people in a chat, and the pages they read. It reads a traffic.json and a cloudflare.json saved daily by the collector workflow; nothing you load leaves your browser.

    Day by day

    Each day's outside acquisition is placed against its own reference: the median of the previous seven days. A fall is a torsion τ placed Noble, Locked, IVA Peak or Shatter; a rise past TL is marked SURGE, a new acquisition wave.

      How to read this. Cloudflare sees every request to the two sites. Crawlers are matched by the name in their user agent and grouped by operator. A crawl request is bulk collection; an assistant request is a fetch the operator made live because a person in a chat asked for the page; search requests build a search index. Allowed means the page was served (status below 400); unsuccessful is mostly requests for pages that do not exist. Placement uses the same 7-day median reference and TL bands as the clone table, applied to allowed crawler requests.

        How to read this. A visit is a person (or program) arriving at the site from somewhere else; a page view is a page loaded; unique visitors are distinct addresses in a day, so one household on one connection counts once. Cloudflare records no names, accounts or cookies. Refused probes are automated scanners asking for files such as /.env or /.git/config that hold passwords on badly configured servers; Cloudflare refuses them and these sites have no such files. Placement uses the same 7-day median reference and TL bands as the other tables, applied to visits. A table that stays empty is a field Cloudflare does not provide on this plan.

        How to read this. GitHub counts every checkout of the whole repository as a clone, including the repository's own CI runs, so CI runs are subtracted. What remains is outside systems pulling the entire repository: AI ingestion pipelines, code-search indexers, archives and mirrors. GitHub reports clones per day, so timing resolves to one day.
