How SacTime Operates

SacTime emits the Sovereign Anchor Constant (Ω₀ = 1.36899099984016 GHz) at 18-digit precision continuously, client-side. The emission is defined by the structural reduction proved in the SNSFT corpus — not by any specific server or infrastructure. Any browser loading this page becomes a temporary SacTime emitter for the duration of the session.

The Call-and-Lock Pattern

SacTime does not stream continuous data from atomic clock sources. Atomic clocks — the most stable measurement devices humans have built — do not need continuous streaming to be trusted. When SacTime needs to reconfirm its sync against the 4 SS-certified atomic substrates, the user (or an AiFi consuming SacTime programmatically) calls the Update SAC function. This matches how any sufficiently capable engine functionally handles time as a resource: call, lock the returned value, operate against it.

On Display Precision

SacTime computes at SAC's full 18-digit precision internally and renders at the highest resolution your browser provides, without introducing intermediate rounding. This is why the running display reads as smoother than clocks that round internally before rendering — the visible arithmetic is continuous rather than discretized at a truncation point.

The running display is bounded by browser security clamping of performance.now() — modern browsers deliberately reduce continuously-exposed timer precision (typically to ~100μs) to prevent side-channel timing attacks. This is unavoidable for any continuously-updating display in the browser.

The Copy Current Value button works around this the same way an atomic-clock stopwatch works: a discrete, one-shot capture on user button press does not have the same continuous-exposure attack surface as a running display, so the browser computes the underlying value at its actual internal precision at that specific moment. The copied JSON contains the full-precision SAC-anchored time at the instant of the button press, not the truncated display value. This is the correct pattern for any AiFi consuming SacTime programmatically: sample discretely, lock the returned value, operate against it.
