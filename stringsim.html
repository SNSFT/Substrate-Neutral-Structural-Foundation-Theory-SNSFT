GROUNDING

τ = B/P, where B is Behavior and P is Pattern, two of the four PNBA primitives. TL = Ω₀/10 = 0.136899099984016, with Ω₀ = 1.36899099984016 GHz. Noble: τ = 0. Locked: 0 < τ < TL_IVA (0.88 × TL). IVA Peak: TL_IVA ≤ τ < TL. Shatter: τ ≥ TL.

A stretched string is a load B against a holding rigidity P, the same threshold shape as the Tacoma bridge and shattering glass. Here the dial is calibrated so the source's qualitative break point sits at τ = TL. After the break, each new pair has equal B on both charges, so B_out = |B₁ − B₂| = 0 by Same-B Necessity and each pair is Noble.

The simulator does not claim a measured value for string tension or pair energy; it inherits the Layer-0 boundary from the formal reduction at [9,9,3,22].

REPORTED BY THE SOURCE
  • Two connected charges are pulled apart, and the energy stored in the connection grows with the separation.
  • When enough energy accumulates (E = mc²), the string breaks and a new particle-antiparticle pair forms. The result is two pairs, not one separated pair.
  • Run on a chain of 13 trapped ions, from an out-of-equilibrium start, detecting effective charges as the system evolves.
  • A classical computer modeled the same process and agreed with the experiment at this scale.
  • Google (superconducting circuits) and QuEra (neutral atoms) recreated related string-breaking models on other hardware.
