THE RULE

Each base carries a donor count and an acceptor count.

A (1,1)   T (1,1)   G (2,1)   C (1,2)

For a pair x·y:

bonds = min(dx,ay) + min(dy,ax)
capacity = dx+ax+dy+ay
open = capacity − 2·bonds

A pair with open = 0 has no unsatisfied capacity left. That is Noble.

EXPORT
FASTA sends the sequence you are looking at to any other tool. CSV gives you the table behind the picture.
FASTA writes the current window with a header naming the source and coordinates — paste it into BLAST to ask whether it occurs anywhere known. CSV emits one row per position: index, reference, complement, bonds, and each substitution with its open capacity. Both write the visible window, capped at 20,000 positions.
